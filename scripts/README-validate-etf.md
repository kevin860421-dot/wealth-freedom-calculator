# ETF 驗算說明

## 執行方式

```bash
npm run validate-etf
```

## 驗證範圍

### App 內建 10 檔
0050、0056、006208、00878、00900、00919、00929、00934、00935、00940

### 網路額外 10 檔
00939、00946、00713、00918、00915、00944、00945、00947、00941、00692

## 比對項目

1. **股價**：App 內建 vs 網路查得（CMoney、Yahoo、各財經網）
2. **殖利率**：年配息 ÷ 股價，與網路公告比對
3. **二代健保門檻**：54C 計入 ≥2 萬、2.11% 公式驗證
4. **手續費**：0.1425%、最低 20 元驗證

## 誤差說明

- 股價、配息隨市場變動，App 為試算參考值
- 股價誤差 <25%、殖利率誤差 <40% 視為可接受
- 00934、00935 等股價變動大，建議定期至官網更新

## 資料來源

- Money Daily、UpToGo、CMoney、Yahoo 財經
- 證交所、各投信官網除權息公告
