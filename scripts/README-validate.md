# 表格驗算說明

## 執行方式

```bash
npm run validate
```

或

```bash
node scripts/validate-table.mjs
```

## 驗證項目

1. **手續費**：0.1425%，最低 20 元（依券商買入費率）
2. **二代健保補充保費**：54C 計入 ≥2 萬時課 2.11%
3. **54C 應稅額**：本次股息 × 54C 佔比
4. **扣抵稅額**：8.5% 上限 8 萬／年
5. **須扣除資金**：補稅 + 補充保費 + 手續費
6. **本次再投入**：(股息 - 須扣除) × 再投入比例
7. **本金餘額**：1萬、100萬、1億、1兆 四組首期驗證

## 參考來源

- 二代健保補充保費 2.11%：健保署公告
- 54C 股利所得：綜合所得稅申報
- 手續費 0.1425%：一般券商買入費率
