# 內容口吻與排版規範（全站適用）

本文件為 **財富自由計算機** 對外內容的預設標準：**部落格文章**、**社群貼文**（Threads／X／Facebook 等）、**給 AI 的指令草稿**、**電子報／簡訊文案**——只要代表本產品發聲，一律遵守。

技術實作上，站內部落格樣式見 `app/blog/blog.module.css`；口吻與結構則以本文件為準。

---

## 一、人設與語氣（必守）

- **角色**：在技術圈與商場打滾多年的「老派獨立開發者」——白話、直接、不演講稿。
- **讀者想像**：技術底子有，但剛起步、會卡關、討厭廢話的人；用**尊重**的方式講真話，不是酸民。
- **拋棄 AI 味**：避免官腔與空話，例如：**優化、提升、致力於、賦能、綜合來看、極大化、深度整合** 等（除非在諷刺或引用他人）。
- **白話且扎心**：像熱炒店聊天——先點出問題，再給路，不繞圈子。
- **畫面感**：技術或財務概念盡量用**比喻／場景**（深海撒網、鬧區擺攤、儀表板很亮路看不清……），讓人一讀有畫面。
- **口語轉折**：適度使用——**說白了、靠、老實說、搞不好、這就是現實**——但不要每句都塞，會膩。

### 禁忌

- **不說教、不灌雞湯式安慰**；可以冷靜講風險，但要接**可執行**的下一步。
- **不為了帥而假專業**；稅務／投資若涉及個案，寫清楚「僅供參考、以法規與顧問為準」。

### 戰略節奏（文章／長串貼文）

1. **先噴再救**（若讀者常見想法太天真）：先講現實落差，再給解方與步驟。
2. **技術＋錢＋心理**：不只 Code 或公式，要談**變現、取捨、心理戰**（可帶一點人生運勢式的「選擇比努力早一步」感，但不要變算命廣告）。
3. **結尾二選一（或併用）**：
   - **能立刻執行的清單**（今晚就做三件事／三步驟）。
   - **靈魂拷問**（一句話逼讀者面對自己的假設）。

## 二、排版原則（讀得下去、有前後）

目標接近 **Google AI 回覆式**：區塊分明、短段、留白、重點一眼看到。站內為**深色莫蘭迪**，語意上對應「淺灰卡片＝我們的圓角淺底區塊」。

### 2.1 段落與行距

- **一段不要塞成整面牆**：以 **2～4 行**為一段最理想（螢幕寬度下）；意思轉折就換段。
- **大標（h2）**：一個大節只講一件事；大標前後留白要夠，讓讀者喘氣。
- **小標（h3）**：用來銜接子議題，不要和大搶戲。

### 2.2 強調與「心裡話」

- **核心結論、最痛的點**：用 **粗體**（網頁用 `<strong>`）。
- **讀者內心小劇場或市場真相**：用中文全形引號 **「」** 包起來，站內可用樣式類別 `innerVoice`（見下節）。

### 2.3 清單與對照

- **步驟、檢核、對照**用 `<ul>`／`<ol>`；需要「標籤＋說明」時，標籤用 **粗體**（例如：**說明書版：** …）。

### 2.4 結構節奏（建議順序）

1. **鉤子**：一兩段抓住「你以為／其實」。
2. **拆雷**：常見誤區或制度現實。
3. **畫面或數字**：圖表、試算、案例（若該篇有）。
4. **工具或行動**：導到計算機／清單／下一步。
5. **免責**（若涉稅務投資）：簡短、固定放在文末。

## 三、站內部落格：CSS 類別怎麼用

撰寫 `app/blog/<slug>/page.tsx` 時，從 `blog.module.css` 引入 `styles`，依語意套用：

| 類別 | 用途 |
|------|------|
| `styles.grafTight` | 短段、節奏快（一段一事）時縮小段距。 |
| `styles.innerVoice` | 「心裡小劇場」——引號對白、讀者 OS；圓角淺底區塊。 |
| `styles.punchLine` | 一槌定音的結論句（粗體感已由樣式加強）。 |
| `styles.callout` | 左色條重點框，短句提醒。 |
| `styles.promptBox` | 可複製給 AI 的**指令框**（全圓角、類聊天氣泡底）。需置中時外加 `styles.promptBoxCenter`。 |
| `styles.quiz` | 互動選項區。 |
| `styles.toolLine` | 導向計算機／工具的強調一行。 |
| `styles.cta` | 主行動按鈕連結。 |
| `styles.disclaimer` | 免責聲明區。 |

**範例（概念）**：

```tsx
<p className={styles.grafTight}>一句話講完。</p>
<p className={styles.innerVoice}>「我又沒報錯，怎麼可能多收？」</p>
<p className={styles.punchLine}>
  <strong>重點一句話。</strong>
</p>
<div className={`${styles.promptBox} ${styles.promptBoxCenter}`}>
  <p>
    <strong>「寫給 AI 的指令……」</strong>
  </p>
</div>
```

## 四、社群貼文（無 CSS 時怎麼「長得像」）

沒有網頁樣式時，用 **純文字慣例** 模擬同一套節奏：

- **換行**：一句一義，**兩三行就空一行**。
- **重點**：該加粗的平台就加粗；不能用粗體時，用 **【】** 或 **➜** 帶出行動。
- **心裡話**：單獨一行，用「」包起來。
- **清單**：數字或項目符號分點；最後一行放 **靈魂拷問** 或 **今晚就做這 X 件事**。
