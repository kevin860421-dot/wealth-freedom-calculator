# 股利相關稅費說明（參考）

## 1. 二代健保補充保費（拿錢時扣）

- **費率**：2.11%
- **起扣點**：單筆 2 萬元（含）以上
- **扣除方式**：源頭扣繳，公司發放股利時先扣，實領為扣繳後金額
- **試算**：若領 3 萬股利 → 30,000 × 2.11% = 633 元扣繳，實領 29,367 元
- 參考：元氣網、永豐金證券

## 2. 股利所得稅（隔年 5 月報稅）

可擇優選擇一種方式申報。

### 方式 A：合併計稅（適合小資、一般上班族）

- **做法**：股利併入薪資等綜合所得一起計算稅額
- **優點**：可享 8.5% 可抵減稅額
- **上限**：抵減上限 8 萬（約當股利 94 萬以內）
- **結果**：若綜所稅率較低（5% 或 12%），抵 8.5% 通常少繳或可退稅
- 參考：StockFeel 股感

### 方式 B：分開計稅（單獨 28%）

- **做法**：不問其他所得，股利所得直接 × 28% 計算應納稅額
- **適用**：高所得者（通常稅率級距已到 30%、40% 以上）
- **優點**：避免股利併入總所得拉高級距（例如跳到 40%），用 28% 固定稅率可能較省
- 參考：萬集會計師事務所、聯捷聯合會計師事務所
